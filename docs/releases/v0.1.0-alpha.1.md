First public prerelease of **Nix820 Pro**, an independent AK820 Pro configurator for Linux.

- Wired USB: Base/Fn remapping, keyboard/modifier/media/browser destinations, lighting, TFT images/GIFs, clock sync, device settings and resets.
- 2.4 GHz: selected-key Base/Fn remapping, lighting, device settings and both resets.
- Local profiles/display presets, XDG storage and migration from the earlier Keyboard Studio folders.
- Independent charcoal/gray/yellow interface and 0BSD license for original project code.

Download the Linux x86_64 archive and checksum file below. Verify the checksum, extract the archive and follow **INSTALL.md**, including the optional HID access rule if needed. The archive includes a user installer/uninstaller, third-party notices and build information. The binary is built on **Ubuntu 24.04 x86_64** and uses system graphics libraries; it is not a self-contained AppImage.

This is an alpha intended for feedback. The project owner tested wired and wireless operation; other firmware/distribution combinations remain unverified. The editor shows local saved values, not live keyboard readback.

Known limits:

- Whole-layer defaults and factory Fn restoration need wired USB. Wireless **Use normal key** assigns the printed key explicitly.
- TFT uploads and clock sync are wired-only. Bluetooth, macros and custom per-key lighting are not implemented.
- Transfers stop on unexpected replies without automatic retries. A missing acknowledgement can leave the physical outcome unconfirmed.

For bug reports, include the version, Linux distribution, wired/receiver mode and exact error. Do not attach unreviewed raw USB captures; they can contain unrelated input and machine metadata.

No raw captures, private profiles or display presets are included in the source or binary archive.
